# Abril Linares Mendoza

Personal site. One scrolling page, plus a photographs view with filters in the URL.

Source: [github.com/adlm6/abril-linares-mendoza](https://github.com/adlm6/abril-linares-mendoza)

## Scripts

```bash
npm install
npm run dev
npm run build
```

`npm run dev` serves the app at `http://localhost:3000`.

`npm run build` runs `next build`. This is a normal Next.js App Router app: no static export, no `basePath`.

## Host

Vercel’s free tier. Import this repository at [vercel.com/new](https://vercel.com/new), leave the framework preset as Next.js, and deploy. The root directory is the repository root. Build command: `next build`.

Copy and the design constraints live in `docs/site-plan.md`. Repository rules are in `.cursorrules`.
